# English A0 → A2

Приложение для коротких самостоятельных занятий: путь по юнитам, режим урока по одному заданию, аудио, проверка и тест блока. Сейчас заполнены Unit 1–4, остальные добавляются по мере прохождения.

Сайт: <https://zhenja199675-del.github.io/english123/>

## Как заниматься

- **Слова** повторяй в Anki: 5 слов и 2 фразы перед занятием.
- **Занятие** — 8 заданий: аудирование, тренажёр, практика по грамматике. Это 10–15 минут.
- **Правило** открывается кнопкой «?» прямо внутри занятия; в уроке оно идёт первым.
- **Пять попыток** на задание: после второй и третьей появляются подсказки, правильный ответ показывается только после пятой.
- **Тест блока** — 10 вопросов, порог 80%. Ответ с подсказками в зачёт не идёт. Результат сохраняется на главной.
- **Сканы Murphy** остаются в уроке как справочник, но не заменяют задания.

## Экраны

- **Главная** — следующий урок, цель дня и путь по юнитам.
- **Занятие** (`#play/u1`) — одно задание на экран, прогресс, проверка и «Дальше».
- **Урок** (`#lesson/u1`) — правило, слова, страницы книги и вся практика списком.
- **Словарь**, **Ошибки**, **Прогресс** — справочник, журнал ошибок и статистика.

## Аудио

Звук лежит в `audio/` в виде MP3, индекс — `audio/manifest.json` (точный текст → файл). Синтез локальный, через Kokoro TTS, без внешних сервисов и оплаты.

Повторная генерация из папки `app`:

```powershell
.venv\Scripts\python.exe tools\tts\generate.py
```

Скрипт берёт тексты из `data.js` и `exercises.js`, пропускает уже готовые файлы, новые складывает в `audio/`. Если файла нет в манифесте, кнопка «Слушать» использует голос браузера.

## Файлы

- `index.html` — разметка, маршрутизация, плеер занятия и логика прогресса.
- `theme.css` — оформление.
- `data.js` — уроки, слова, аудирование, тренажёр и дополнительные задания.
- `exercises.js` — интерактивные задания по грамматике юнитов.
- `theory.js` — подробные объяснения правил для каждого юнита.
- `murphy/` — сканы книги и ключ.
- `audio/`, `tools/tts/` — звук и скрипт его генерации.
- `sw.js`, `manifest.webmanifest`, иконки — офлайн и установка на телефон.

Прогресс хранится в `localStorage` браузера и не синхронизируется между устройствами.

## Обновление

После правок `data.js`, `exercises.js`, `theory.js` или `theme.css` подними версии: `data.js?v=5`, `exercises.js?v=1`, `theory.js?v=1`, `theme.css?v=3` в `index.html` и `sw.js`, плюс `CACHE` в `sw.js`.

## Локальный запуск

Двойной клик по `start.cmd` или из папки `app`:

```powershell
python -m http.server 8080
```

Открыть `http://127.0.0.1:8080/`.
