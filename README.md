# Приложение курса (локальное)

Живёт только на твоём компьютере и телефоне, в интернет не выкладывается. Поэтому внутри есть страницы книги Murphy из твоего скана.

## Запуск

Двойной клик по `start.ps1`. Откроется браузер с адресом `http://127.0.0.1:8080/`.

В окне PowerShell будет вторая строка — адрес для телефона, вида `http://192.168.0.12:8080/`. Он работает, пока компьютер включён и телефон в той же Wi-Fi. Окно PowerShell не закрывать, иначе сервер остановится.

Если Windows спросит про доступ в сеть для Python — разрешить для частных сетей.

## Что внутри

- `index.html` — разметка и логика.
- `theme.css` — всё оформление: цвета, карточки, типографика, иконки меню. Правки дизайна только здесь.
- `data.js` — уроки, слова, задания. При изменении поднять версию в `index.html` (`data.js?v=3` → `v=4`) и `CACHE` в `sw.js`, иначе браузер покажет старое из кеша.
- `murphy/` — страницы книги, вырезанные из скана: страница правила и страница упражнений на каждый юнит, плюс ключ с ответами.
- `sw.js`, `manifest.webmanifest`, иконки — офлайн и установка на телефон.

Прогресс, ответы и журнал ошибок хранятся в `localStorage` браузера. Данные никуда не уходят.

## Структура урока

1. **Мерфи: Unit N** — страница правила из книги. Тап по странице открывает её крупно.
2. **Домашка по книге** — страница упражнений, поле «Мои ответы» и кнопка «Показать ключ». Пишешь ответы, сверяешься.
3. **Мои пояснения** — разбор ловушек для русскоязычного ученика.
4. **Слова урока** — с транскрипцией и русской подсказкой.
5. **Тренажёр** — те же темы с автопроверкой.
6. **Дополнительно** — мои упражнения.

## Ограничения

- Картинки страниц весят ~2 МБ на четыре юнита. Дальше добавляю по мере прохождения, чтобы папка не распухла.
- Сервер локальный: с телефона работает только дома. Вне дома — только если открывать файлы на самом телефоне, но там не будет сохранения прогресса.
